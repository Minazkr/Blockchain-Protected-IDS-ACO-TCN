# Raspberry Pi Deployment (C++)

This folder contains the C++ implementation used for deploying the intrusion detection model on resource-constrained devices (Raspberry Pi).

## Contents

- Lightweight inference code
- Preprocessing compatible with the Python training pipeline
- Support for real-time flow processing

## Notes

- The model weights are exported from the Python training stage.
- This implementation focuses on low latency and low memory usage.
- Detailed build and run instructions will be added here.
